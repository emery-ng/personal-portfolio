Student Expense Tracker

Log it in a few taps. See where your money goes.

Mobile app · React Native · SQLite · Course project

Tested on an iPhone with Expo Go. The screenshots show my own test entries.

Add, edit, delete Full control of every entry
3 views All, this week, and this month, each with totals
Works offline Saved on your phone, no account or server

Why I built it

Small purchases add up fast, and without a record it's hard to say where the money went. I built this app to make logging them quick, so you can see what you've spent this week or this month, and on what. Knowing where your money goes is the first step to budgeting.

What it does

  • See where your money goes: Spending is broken down by category, biggest first.
  • Check any period: Totals for this week, this month, or everything.
  • Log it fast: Amount and category are all you need, the date fills in as today, and it all happens on one screen.
  • Keep it private: Everything stays on your phone, with no account, and it works offline.

How it's built

I built it with React Native and Expo, in JavaScript. The data lives in a SQLite database on the phone, and the screen uses React hooks to keep everything in sync.

  • The table is created on first launch, and an older database without a date column is upgraded automatically.
  • Amount and category are checked before saving, and every insert, update, and delete uses a parameterized query, so typed text never runs as SQL.
  • The week and month filters and the category totals are calculated in the app from the saved entries, so they update the moment you add, edit, or delete.
  • Dates are read in local time, so "this week" and "this month" follow your calendar.
  • Edits happen in a pop-up, and a short message confirms each change.
CREATE TABLE IF NOT EXISTS expenses (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  amount REAL NOT NULL,
  category TEXT NOT NULL,
  note TEXT,
  date TEXT NOT NULL
);

INSERT INTO expenses (amount, category, note, date) VALUES (?, ?, ?, ?);

The question marks are placeholders, and the values are passed separately.

What's next

Next I'd add monthly budgets, spending charts, recurring expenses, and backup across devices.

Limits: invalid input fails silently, deleting doesn't ask first, and amounts are stored as decimals instead of cents. I've only tested it on an iPhone through Expo Go, with no automated tests.
